# CLI Contract: `timekotiki` 0.1.0

Публичный API по принципу IV конституции. Любое несовместимое изменение этого файла →
MAJOR-версия пакета.

## Общие правила

- stdout — только результат команды; stderr — прогресс, предупреждения, ошибки.
- Нет интерактивных промптов.
- Прогресс в TTY — обновляемая строка; вне TTY — строка на этап; `--quiet` выключает.
- Цвет не используется.
- Сеть: только `models pull`. Остальные команды обращаются лишь к Ollama на loopback.

## `timekotiki generate FILE [options]`

Генерирует главы для локального видео- или аудиофайла.

| Флаг | Значение | По умолчанию | Требование |
|------|----------|--------------|------------|
| `FILE` | путь к локальному файлу | — (обязателен) | FR-001 |
| `--format {text,json,vtt}` | формат вывода | `text` | FR-005, FR-008 |
| `--json` | синоним `--format json` | — | FR-006 |
| `-o, --output PATH` | записать в файл вместо stdout | stdout | FR-007 |
| `--force` | разрешить перезапись `--output` | выкл. | FR-007 |
| `--min-chapter DURATION` | мин. длительность главы: `90`, `1m30s`, `5m` | `1m` | FR-009 |
| `--max-chapters N` | максимум глав | не ограничено | FR-009 |
| `--title-language LANG` | язык заголовков (ISO 639-1) | язык речи | FR-010 |
| `--speech-language LANG` | язык речи, без автоопределения | авто | FR-002 |
| `--asr-model NAME` | модель faster-whisper | `large-v3-turbo` | — |
| `--llm-model NAME` | модель Ollama | `qwen2.5:7b-instruct` | — |
| `--no-cache` | не читать кэш расшифровки | выкл. | FR-012 |
| `-q, --quiet` | без прогресса в stderr | выкл. | FR-011 |

**Текстовый вывод** (`text`):

```text
00:00 Вступление
04:12 Настройка проекта
1:02:30 Итоги и вопросы
```

**JSON-вывод**: по схеме [result.schema.json](result.schema.json).

**WebVTT-вывод** (`vtt`):

```text
WEBVTT

1
00:00:00.000 --> 00:04:12.000
Вступление

2
00:04:12.000 --> 01:02:30.000
Настройка проекта
```

## `timekotiki models status [--json]`

Показывает, установлены ли локально ASR-модель и LLM (без сети). Принимает
`--asr-model` и `--llm-model`. Код 0, если обе модели на месте, иначе 6.

## `timekotiki models pull [--asr-model NAME] [--llm-model NAME]`

Скачивает модели. Это единственная команда, которая использует сеть. Прогресс выводится в stderr.

## `timekotiki cache clear`

Удаляет кэш расшифровок. Код 0, даже если кэш пуст.

## `timekotiki --version` / `--help`

## Коды выхода

| Код | Класс | Примеры |
|-----|-------|---------|
| 0 | Успех | — |
| 2 | Ошибка использования | неизвестный флаг, `--max-chapters 0`, плохой `--min-chapter` |
| 3 | Вход недоступен | файл не найден, нет прав, передан URL |
| 4 | Формат не поддерживается / файл повреждён | контейнер не открывается |
| 5 | Нет звука или речи | нет аудиопотока; VAD не нашёл речь |
| 6 | Модели/бэкенд недоступны | модель не скачана, Ollama не запущена, `OLLAMA_HOST` не loopback |
| 7 | Ошибка обработки | сбой распознавания или LLM после повторной попытки |
| 8 | Конфликт вывода | `--output` существует без `--force`, каталог не пишется |
| 130 | Прервано (Ctrl+C) | — |

Сообщение об ошибке — одна строка `timekotiki: error: <текст>` в stderr, при необходимости
дополненная строкой `hint: <команда>`.

## Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `TIMEKOTIKI_CACHE_DIR` | каталог кэша расшифровок |
| `OLLAMA_HOST` | адрес Ollama; должен быть loopback |
| `HF_HOME` | каталог моделей faster-whisper (стандарт Hugging Face) |
| `NO_COLOR` | соблюдается (цвет не используется) |
